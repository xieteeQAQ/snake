## 游戏
- 游戏场景在一个封闭的平面地图, 玩家有`蛇头`和`蛇身`两部分, 地图会生成`食物`和`弹幕`
- 玩家蛇头碰撞到食物时会吃掉食物, 累计吃掉 `3` 个食物获得一段蛇身
- 玩家蛇头和蛇身都有类似的`健康系统`, 每有一节身体玩家血量上限`+5`, 碰撞到弹幕时会相应地扣血
- 玩家每长一节身体时, 会获得数值为 `5` 的`额外血量`(类似护盾值)
- 玩家拥有`技能`, 目前只实现了一个技能
- 玩家移动有摩擦阻力
- 按键:

    | 按键 | 说明 |
    |:----:|:----:|
    | `AWSD` | 方向键, 控制玩家移动方向 |
    | `F` | 技能`冲刺`, 短暂冲刺 |
    | `G` | 消耗身体, 每节身体+5血量, 最多消耗三节身体 |
    | `1` | 开启debug模式 |
    | `2` | 显示碰撞箱(需要先开启debug模式) |

- tip: 没有退出游戏按键, 如果程序没有卡死或崩溃, 可以直接点系统的关闭键, 必要情况可以直接kill
